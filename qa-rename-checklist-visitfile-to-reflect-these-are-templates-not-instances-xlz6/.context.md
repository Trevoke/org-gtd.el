The objects stored in checklists.org are TEMPLATES (bare heading + "- [ ]" items) that
org-gtd-checklist-insert copies into a fresh instance. A "checklist" arguably names the
instance you actually work, so the current names conflate template vs instance.

Consider renaming for clarity, e.g.:
  - org-gtd-checklist-visit -> org-gtd-checklist-template-visit (or ...-templates-visit)
  - file org-gtd-checklist-file-name "checklists" -> "checklist-templates"
  - org-gtd-checklist-names / --items likewise reference "templates"
