In the org-gtd-view-manager list transient, the RET action is labeled 'Render' (org-gtd-view-manager.el, list prefix: ("RET" "Render" org-gtd-view-manager--list-render)).

Problems with 'Render':
- On an EMPTY store, RET opens the Engage view, so 'Render' doesn't describe what happens.
- Even with saved views, 'Render' is jargon; 'Open' or 'Show' reads plainer for 'open this view as an agenda'.

Suggested: relabel to 'Open' (or 'Show'/'View'). Consider the empty-state teaching line too ('...or RET to open Engage') so the verb matches.
