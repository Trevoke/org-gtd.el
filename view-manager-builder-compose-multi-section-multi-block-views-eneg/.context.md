Biggest gap surfaced in QA (2026-07-09). The builder only produces a SINGLE-section view (one type + filters). Real engage/reflect views are multi-section: e.g. a calendar/agenda section, a next-actions section, a habits section, a delegated/waiting section, each its own block.

The view DSL already supports composite views (blocks / additional-blocks / view-type / group-by), but the manager's builder exposes no way to add, order, or remove sections. This is central to the 'manage my whole GTD system view' intent from the original design discussion.

Needs design: how to represent a list of sections in the builder transient (add section / pick each section's type+filters / reorder / delete), how the live preview shows the composite, and how it compiles to the DSL's blocks form.
