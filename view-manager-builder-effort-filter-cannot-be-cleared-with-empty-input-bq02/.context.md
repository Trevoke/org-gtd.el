In the builder, pressing e and entering an empty string does NOT clear the effort filter -- it errors ('Effort needs a duration like 30m'). Area-of-focus (and other value readers) treat empty input as 'unset the filter', but org-gtd-view-manager--read-effort passes the raw input straight to --effort->dsl, which user-errors on a non-matching (empty) string.

Fix: in --read-effort, treat blank input as nil (unset) before calling --effort->dsl, mirroring --read-area's (if (string-blank-p v) nil v).
